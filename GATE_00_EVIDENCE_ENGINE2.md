Standard sorting algorithms like QuickSort or MergeSort execute in $O(N \log N)$ time by sorting the entire array of $N$ destinations. However, travelers typically only browse the Top-$K$ recommendations (e.g., $K=5$ or $K=10$). By building a custom Max-Heap, we construct the heap in linear $O(N)$ time using Floyd's bottom-up heapification and extract the Top-$K$ destinations in $O(K \log N)$ time. For $K \ll N$, total runtime is $O(N + K \log N)$, which is asymptotically superior and avoids sorting the remaining $N-K$ irrelevant elements."* |
