| Faculty question asked at Decision level, and the answer given   | Question: Why did you choose to build a custom Binary Max-Heap from scratch rather than simply calling standard sorting functions like std::sort() or JavaScript Array.prototype.sort()?    Answer: Under the KLE Tech BCA framework for Engine 2 (Logic & Rule), the core requirement is to construct one foundational data structure by hand with mathematical justification. Standard sorting algorithms like QuickSort or MergeSort execute in O(N log N) time by sorting the entire array of N destinations. However, travelers typically only browse the Top-K recommendations (e.g., K=5 or K=10). By building a custom Max-Heap, we construct the heap in linear O(N) time using Floyd's bottom-up heapification and extract the Top-K destinations in O(K log N) time. For K << N, total runtime is O(N + K log N), which is asymptotically superior and avoids sorting the remaining N-K irrelevant elements.   |
